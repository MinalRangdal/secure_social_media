🎓 How Cryptographic Verification Works

SHA-256 Hash Function: A cryptographic algorithm that converts any input (in this case, image bytes) into a fixed 64-character hexadecimal string.

What This Verification Proves:

  • Integrity: Any modification to the image (even a single pixel) produces a completely different hash
  • Authenticity: The stored hash proves this exact image was uploaded by the original user
  • Non-Repudiation: The uploader cannot deny posting this specific content
  • Tamper Detection: Screenshots, edits, or re-compressions will fail verification
